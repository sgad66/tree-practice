# 枝径 TreePath

数据结构在线编程练习站（C 语言）：树专题、通用 DS，以及对齐 BUPT《结构分析》课件的章节题。浏览器内编写**完整 C 程序（含 main）**。

## 分类与题量

| 分类 | 题量 |
|------|------|
| 树专题（8 类） | 100 |
| 通用 DS（数组/栈/队列/链表/哈希/堆/图/排序） | 74 |
| 课·导论与ADT | 6 |
| 课·算法分析 | 10 |
| 课·线性表 | 10 |

| 课·串与匹配 | 10 |

| **合计** | **246** |

## 输入 / 输出

仅数字与 `NULL`（无方括号）；判题按 token 比较。详见题面与 Project 文档。

